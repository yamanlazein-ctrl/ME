## 8. الحكم النهائي (Verdict)

**هذا "منتج جديد يُبنى فوق منطق عمل قابلاً لإعادة الاستخدام"** — وليس تعديلاً صغيراً ولا إعادة كتابة كاملة.

| ما يُحافَظ عليه فوراً | ما يُعاد بناؤه | ما يجب عدم لمسه |
|---|---|---|
| منطق العمل الكامل (فواتير/محاسبة/مخزون/أسعار) | RLS فعلي + عزل شركات | `desktop/` كاملاً (Tauri + PG + DPAPI + ترخيص مخبوز) |
| الواجهة React | هوية مركزية + جلسات لكل جهاز + إلغاء | `bake-desktop-license.ts` |
| `packages/shared` | ترخيص→اشتراك + فوترة | `admin-dashboard` + `license-server` |
| كل repos البوستغرس | إدارة أجهزة + force-logout | بيانات العملاء الحالية |
| JWT/Argon2/Ed25519-verify | بنية إنتاج (PG مُدار, Redis, TLS, KMS, CD) | أسماء Rust غير المتتبعة (احفظها، لا تعدّلها) |
| auth/rbac/idempotency middleware | Offline/mزامنة (إن اعتمدت) | WIP تعدد العملات (أكمله، لا تعِده) |
