# T128 — desktop revoke screen shows the phone's unsynced count

Not available, skipped as the task allows. The hub's device list (`GET /api/sync/hub/devices`, type `HubDevice`) carries
id, platform, hostname, label, last seen and revoke fields only. The number of documents a phone has not yet sent exists
only in that phone's own outbox; the hub never learns it until the phone pushes. Showing a number on the desktop would
need a new hub endpoint and a phone-side report, which changes the sync contract and is outside this build.
The phone itself shows its own unsynced count before logout and wipe (FR-04, E18).
