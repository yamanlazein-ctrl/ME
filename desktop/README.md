# ERP Desktop

Tauri 2 desktop shell for the Motard Fabrics ERP web app.

## Development

```bash
cd desktop
npm install
npm run tauri:dev
```

## Build

```bash
npm run tauri:build
```

> Note: `tauri:dev` runs the root web app dev server first (`localhost:5173`)
> and the backend API should be running on port 8080.
